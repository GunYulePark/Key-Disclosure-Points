# 공시 검토실 · Key Disclosure Points

종근당·종근당홀딩스·경보제약의 공시 변경사항, 점검 포인트와 공식 원문 근거를 공개 열람하는 사이트입니다.

**사이트: https://gunyulepark.github.io/Key-Disclosure-Points/**

## 현재 자료

- 기준일: **2026.10.16**. 실시간 수집 결과가 아닙니다.
- 회사별 점검 11건: P1 10건, P2 1건.
- 추가 정정 검토 후보 4건. 정정 의무를 확정하지 않았으며 내부 초안 대조 전입니다.
- 공식 공시 검색 목록 126건(2026.01.01–10.16, 정정 포함).
- 공통 기준 5개, 출처 경로 12개.
- 종근당건강은 독립 모니터링 대상에서 제외했습니다.

공시 목록 전체의 본문·첨부를 전수 검토한 상태는 아닙니다. AI의 선정 원문 검토와 규칙 비교에 따른 미승인 검토자료이며 원문 근거·회사별 적용조건과 함께 확인해야 합니다. 공시 목록·선정 첨부의 예약 수집은 연결했습니다. 새 규정의 무인 AI 해석·메일 발송은 연결 전입니다.

## 공개판 기능

2026.10.16 보완: 공통 기준의 자기주식보고서 첨부 예외에 종근당의 종전 생략 근거, 6.30 개정 신구조문·현행 PDF·별지서식, 회사별 적용·보고서별 첨부조건·작성 점검사항을 연결했습니다. PDF 원문 링크·실제 페이지 번호·원파일 SHA-256과 선정 페이지 이미지 3장을 제공합니다. [해당 항목 바로가기](https://gunyulepark.github.io/Key-Disclosure-Points/#rules-treasury)

회사·중요도·정정 후보 필터, 키워드 검색, 변화 대조와 주식 변동표, 근거 인용·위치·해시, DART 원문 연결, 공시 날짜 검색·페이지 이동, JSON 다운로드를 제공합니다. 로그인 없이 열람할 수 있습니다.

개인별 검토 메모·담당자·검토 이력, 인증키·메일 수신자·내부 초안은 이 저장소에 포함하지 않습니다. 기존 비공개 사이트의 저장 API를 호출하지 않습니다. [내부 검토 공간](https://ckd-disclosure-desk.yulemu1351.chatgpt.site)은 기존 접근권한을 유지합니다.

## 구성과 업데이트

| 경로 | 용도 |
| --- | --- |
| `src/Desk.tsx` | 공개 열람 화면 |
| `src/style.css` | 반응형 화면 스타일 |
| `src/snapshot.json` | 공개 가능한 기준 자료 |
| `scripts/build.mjs` | 정적 산출물 생성·비공개 API 포함 여부 검사 |
| `docs/` | 실제 GitHub Pages 배포 파일 |

Node.js 22 이상에서:

```sh
npm ci
npm run check
npm run build
npm run preview
```

로컬 미리보기: `http://127.0.0.1:4174/Key-Disclosure-Points/`

자료를 추가할 때 `src/snapshot.json`의 기준일·목록·근거를 함께 갱신하고, `npm run check`와 `npm run build` 후 **소스와 `docs/`를 함께 커밋**합니다. 기존 항목의 변경은 증거와 판단 상태를 확인한 뒤 반영합니다. 공개판에 업무 메모나 수신자 정보를 추가하지 않습니다.

## GitHub Pages 설정

저장소 Settings → Pages → **GitHub Actions**. `.github/workflows/update-disclosures.yml`이 수집·검증 후 Pages artifact를 배포합니다.

상대경로 자산과 `.nojekyll`을 사용하므로 저장소 하위 주소에서 동작합니다. GitHub Pages는 정적 사이트를 제공하며, 로그인·서버 DB·메일 발송 기능은 이 공개판에 포함하지 않습니다.

## 출처

각 항목에 DART 원문 링크와 접수번호를 포함했습니다. 공통 기준·출처 현황에서는 금감원·금융위·거래소·상장회사협의회·국가법령정보센터의 공식 경로 및 확인 수준을 안내합니다.

## 규정 변경·PDF 파일 참조 (v0.2.0)

공통 기준에 제약·바이오 개편 8개 기준과 3개 회사별 반영 검토를 추가했습니다. 7월 보도자료와 8월 후속 모범사례·현재 공시를 연결하고, 권고·조건부·최종기준 대기를 구분합니다.

`규정 파일 추가`는 PDF 원본·페이지별 본문·출처·대상 회사를 브라우저 IndexedDB에 저장합니다(30MB, 600쪽). 파일 원본은 서버로 전송하지 않습니다. 검토된 파일의 SHA-256이 같으면 기존 분석으로 연결하고, 새 파일은 검토 대기로 보관합니다. 키워드 연결은 적용 판정이 아닙니다. 원본과 검토자료 JSON을 Codex에 첨부해 분석을 이어갈 수 있습니다. 자동 OCR·새 규정의 무인 AI 해석·서버 공유 저장은 연결 전입니다. 브라우저 저장소를 지우면 파일이 삭제됩니다.

PDF.js 및 worker/CMap/font/WASM은 동일 버전으로 사이트에서 제공합니다. 외부 CDN으로 업로드 문서를 보내지 않습니다.

## 6단계: PC 없이 수집·상태 갱신

GitHub Actions `Collect disclosures and publish`가 한국시간 월~금 오전 8시(UTC 일~목 23시)에 실행됩니다. 같은 저장소의 갱신은 concurrency 그룹으로 중복 실행을 막습니다. 실행 대기·지연이 있을 수 있고, GitHub 계정의 동시 작업 한도는 공유됩니다. 별도 Codex 데스크톱 예약 작업이나 Gemini 호출은 만들지 않습니다.

수집 엔진은 Python의 공개 DART 목록·게시판 목록·선정 첨부 해시 비교입니다. OpenDART 인증키 없이 공개 검색을 사용합니다. 원문 접근 실패 시 마지막 정상 데이터를 유지하며 상태를 실패/부분 실패로 기록합니다. 현재 선정 경로는 세 회사 공시 목록, 금감원 게시판 2개, 첨부 6개입니다. 규정 내용 해석·시행일 판단·회사별 필수 수정과 메일 전송을 무인으로 처리하지 않습니다.

`monitoring/state.json`에 출처별 최근 성공/실패, 페이지/건수 검증, 공시 누적 목록, 게시물/첨부 식별정보, 검토 대기와 최근 30회 실행을 보관합니다. 조회수는 규정 변경으로 취급하지 않습니다. 기존 분석 범위 밖의 올해 자료는 초기 미검토 자료로 표시합니다. `src/snapshot.json`의 검토 결과·분석 기준일을 자동 변경하지 않습니다. 바뀐 선정 첨부 원본은 Actions artifact에 30일 보관하며 운영 JSON과는 별도로 검토합니다.

사이트의 `수집·운영 현황`에서 실제 실행 이력·미검토 항목·수집 실패·기준자료 일자를 확인합니다. 수동 실행은 저장소 Actions의 Run workflow를 사용합니다. 일반 방문자에게 쓰기 권한을 주거나 토큰을 웹페이지에 넣지 않습니다.

공개 배포는 GitHub Actions Pages artifact 방식입니다. 소스 변경 시 검사→수집→빌드→상태 커밋→Pages 배포 순서입니다. `docs/`는 로컬 산출물 보관용으로 유지합니다. 메일 수신자·내부 기록·업로드 원본은 수집 작업이나 공개 저장소에 포함하지 않습니다.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/collector.py
npm ci
npm run check
npm run build
```
