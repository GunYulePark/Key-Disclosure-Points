# 공시 검토실 · Key Disclosure Points

종근당·종근당홀딩스·경보제약의 공시 변경사항, 점검 포인트와 공식 원문 근거를 공개 열람하는 사이트입니다.

**사이트: https://gunyulepark.github.io/Key-Disclosure-Points/**

## 현재 자료

- 기준일: **2026.10.16**. 실시간 수집 결과가 아닙니다.
- 회사별 점검 11건: P1 10건, P2 1건.
- 추가 정정 검토 후보 4건. 정정 의무를 확정하지 않았으며 내부 초안 대조 전입니다.
- 공식 공시 검색 목록 126건(2026.01.01–10.16, 정정 포함).
- 공통 기준 5개, 출처 경로 12개.
- 종근당건강은 독립 모니터링 대상에서 제외했습니다.

공시 목록 전체의 본문·첨부를 전수 검토한 상태는 아닙니다. AI의 선정 원문 검토와 규칙 비교에 따른 미승인 검토자료이며 원문 근거·회사별 적용조건과 함께 확인해야 합니다. 공시 목록·선정 첨부의 예약 수집은 연결했습니다. 새 규정의 무인 AI 해석·메일 발송은 연결 전입니다.

## 공개판 기능

2026.10.16 보완: 공통 기준의 자기주식보고서 첨부 예외에 종근당의 종전 생략 근거, 6.30 개정 신구조문·현행 PDF·별지서식, 회사별 적용·보고서별 첨부조건·작성 점검사항을 연결했습니다. PDF 원문 링크·실제 페이지 번호·원파일 SHA-256과 선정 페이지 이미지 3장을 제공합니다. [해당 항목 바로가기](https://gunyulepark.github.io/Key-Disclosure-Points/#rules-treasury)

회사·중요도·정정 후보 필터, 키워드 검색, 변화 대조와 주식 변동표, 근거 인용·위치·해시, DART 원문 연결, 공시 날짜 검색·페이지 이동, JSON 다운로드를 제공합니다. 로그인 없이 열람할 수 있습니다.

개인별 검토 메모·담당자·검토 이력, 인증키·메일 수신자·내부 초안은 이 저장소에 포함하지 않습니다. 기존 비공개 사이트의 저장 API를 호출하지 않습니다. [내부 검토 공간](https://ckd-disclosure-desk.yulemu1351.chatgpt.site)은 기존 접근권한을 유지합니다.

## GitHub Pages 설정

저장소 Settings → Pages → **GitHub Actions**. `.github/workflows/update-disclosures.yml`이 수집·검증 후 Pages artifact를 배포합니다.

상대경로 자산과 `.nojekyll`을 사용하므로 저장소 하위 주소에서 동작합니다. GitHub Pages는 정적 사이트를 제공하며, 로그인·서버 DB·메일 발송 기능은 이 공개판에 포함하지 않습니다.

## 규정 변경·PDF 파일 참조 (v0.2.0)

공통 기준에 제약·바이오 개편 8개 기준과 3개 회사별 반영 검토를 추가했습니다. 7월 보도자료와 8월 후속 모범사례·현재 공시를 연결하고, 권고·조건부·최종기준 대기를 구분합니다.

`규정 파일 추가`는 PDF 원본·페이지별 본문·출처·대상 회사를 브라우저 IndexedDB에 저장합니다(30MB, 600쪽). 파일 원본은 서버로 전송하지 않습니다. 검토된 파일의 SHA-256이 같으면 기존 분석으로 연결하고, 새 파일은 검토 대기로 보관합니다. 키워드 연결은 적용 판정이 아닙니다. 원본과 검토자료 JSON을 Codex에 첨부해 분석을 이어갈 수 있습니다. 개인 업로드의 자동 OCR·API 전송·서버 공유 저장은 연결 전입니다. 공식 공개 자료의 반복 AI 분석은 아래 7단계에서 별도로 실행합니다. 브라우저 저장소를 지우면 파일이 삭제됩니다.

PDF.js 및 worker/CMap/font/WASM은 동일 버전으로 사이트에서 제공합니다. 외부 CDN으로 업로드 문서를 보내지 않습니다.

## 6단계: PC 없이 수집·상태 갱신

GitHub Actions `Collect disclosures and publish`가 한국시간 월~금 오전 8시(UTC 일~목 23시)에 실행됩니다. 같은 저장소의 갱신은 concurrency 그룹으로 중복 실행을 막습니다. 실행 대기·지연이 있을 수 있고, GitHub 계정의 동시 작업 한도는 공유됩니다. Codex 데스크톱 예약 작업은 사용하지 않습니다. 이후 단계에서 Gemini API 분석을 같은 클라우드 작업에 연결했습니다.

수집 엔진은 Python의 공개 DART 목록·게시판 목록·선정 첨부 해시 비교입니다. OpenDART 인증키 없이 공개 검색을 사용합니다. 원문 접근 실패 시 마지막 정상 데이터를 유지하며 상태를 실패/부분 실패로 기록합니다. 현재 선정 경로는 세 회사 공시 목록, 금감원 게시판 2개, 첨부 6개입니다. 별도 Gemini 단계가 규정 내용·시행일·회사별 수정 후보를 생성하며, 사람의 확정 판단·메일 전송은 자동 처리하지 않습니다.

`monitoring/state.json`에 출처별 최근 성공/실패, 페이지/건수 검증, 공시 누적 목록, 게시물/첨부 식별정보, 검토 대기와 최근 30회 실행을 보관합니다. 조회수는 규정 변경으로 취급하지 않습니다. 기존 분석 범위 밖의 올해 자료는 초기 미검토 자료로 표시합니다. `src/snapshot.json`의 검토 결과·분석 기준일을 자동 변경하지 않습니다. 바뀐 선정 첨부 원본은 Actions artifact에 30일 보관하며 운영 JSON과는 별도로 검토합니다.

사이트의 `수집·운영 현황`에서 실제 실행 이력·미검토 항목·수집 실패·기준자료 일자를 확인합니다. 수동 실행은 저장소 Actions의 Run workflow를 사용합니다. 일반 방문자에게 쓰기 권한을 주거나 토큰을 웹페이지에 넣지 않습니다.

공개 배포는 GitHub Actions Pages artifact 방식입니다. 소스 변경 시 검사→수집→빌드→상태 커밋→Pages 배포 순서입니다. `docs/`는 로컬 산출물 보관용으로 유지합니다. 메일 수신자·내부 기록·업로드 원본은 수집 작업이나 공개 저장소에 포함하지 않습니다.

```sh
python3 -m unittest discover -s tests -v
python3 scripts/collector.py
npm ci
npm run check
npm run build
```

## 7단계: 무료 API 우선 반복 분석

한국시간 평일 08:00 GitHub Actions에서 수집 → 작은 분할 추출 → 한 규정·한 회사 대조 → 별도 AI 비평 → 인용 검증 → 완료된 AI 초안부터 게시 → Pages 배포를 수행합니다. 오래 걸려도 무료 한도 내에서 처리한다는 운영 방침입니다. PC와 Codex 대화 한도에 의존하지 않습니다.

**결제가 연결되지 않은 Google Free 프로젝트의 API 키**를 저장소 Actions Secret `GEMINI_API_KEY`에 등록하세요. 키를 코드·대화·공개 사이트·GitHub Variables에 넣지 않습니다. 무료 모드는 Google 프로젝트의 결제 상태를 API 키로 자동 판별하거나 유료 키의 과금을 막는 기능이 아닙니다. 유료 프로젝트 키를 넣으면 같은 요청도 청구될 수 있습니다. 무료 모델 사용 가능 여부와 실제 RPM/TPM/RPD는 AI Studio에서 확인합니다. 키가 없으면 `needs_key`를 표시하며 실응답을 검증한 것으로 표시하지 않습니다.

기본 `gemini-3.8-flash`, 실행당·하루 4회, 요청 간 최소 75초, 출력 최대 4,000토큰입니다. PDF는 원본 4쪽씩 직접 제공하고, HWP·HTML 본문은 3,000자 세그먼트로 나눕니다. PDF 전문은 이 분할들을 차례로 읽으며 생략하지 않습니다. 문서가 모두 끝나기 전에도 **완료된 규정 분할·회사 검토**를 부분 결과로 올립니다. 부분 검토 표시와 원문 위치를 남기며 전체 문서 확인으로 표시하지 않습니다.

회사 대조는 한 규정·한 회사씩 합니다. 회사 본문 약 9KB, 현행 기준 약 6.5KB, 규정 인용 주변 발췌 약 6.5KB를 사용하며 입력 추정 상한 60,000을 넘는 호출은 차단합니다. 무료 TPM 충족을 보장하는 수치는 아닙니다. 관련 섹션·페이지 일부를 검색하므로 다른 구간의 예외와 적용 여부는 미확인일 수 있습니다. 단정 대신 불확실성을 기록하고 법률 전수 검토로 취급하지 않습니다. 인용은 발췌문과 원본 양쪽의 ID·위치·문자열을 확인합니다. 스캔 PDF의 문자 일치는 미검증으로 표시합니다.

API 429 응답 시 즉시 호출을 멈추고 24시간의 재시도 금지 시각을 저장합니다. 금지 시각 이후 첫 예약에서 재개하며 무료 한도를 넘겼다고 유료 모델/프로젝트로 전환하지 않습니다. 초과·일일 호출 한도·긴 문서의 추출/회사 대조/비평 캐시는 다음 예약에서 이어갑니다. 큰 자료 한 건이 다른 자료를 계속 막지 않도록 대기 자료를 순환합니다. 전체 정리에는 여러 날·주 이상 걸릴 수 있고 완료 시각은 보장하지 않습니다.

`monitoring/ai-config.json`이 운영 설정, `monitoring/ai-state.json`이 캐시·시도/추정 사용량·진행 상태·초안 이력, `public/data/ai-analysis.json`이 공개 운영 상태입니다. 월 $20·하루 $3 유료 환산 비용 제한은 이 무료 모드에서 제거했습니다. 장부의 `reservedUSD`는 이전 형식과 호환되는 유료 환산 추정값이며 실제 청구액이 아닙니다. 하루 호출 수는 한국시간 기준이고 Google 할당량의 초기화 시각과는 다를 수 있습니다.

모든 AI 결과는 `humanApproved: false`입니다. P1/P2/P3, 필수 수정 후보·권고·조건부·미확인, 정정 검토 후보를 구분합니다. 별도 AI 비평이 지적 없음이어도 사람의 승인으로 취급하지 않습니다. 잘못된 근거·불완전/형식 오류 응답은 게시하지 않습니다. 기존 사람이 검토한 11건과 비공개 메일 기록은 자동 변경하지 않습니다. 메일 발송도 하지 않습니다.

자동 API 전송은 선정된 **공식 공개 자료**에 한정합니다. 개인 브라우저 업로드 PDF·수신자·메일 승인 기록을 보내지 않습니다. Google 무료 서비스의 데이터 이용 조건을 확인하세요. 현재 미연결인 금융위 신규 게시판·KRX·법령센터 등 수집 경로가 이 작업으로 추가된 것은 아닙니다.

검증: `python3 -m pip install -r requirements.txt`, `python3 -m unittest discover -s tests -v`, `npm run check`, `npm run build`. 모킹한 API 테스트는 실제 공개 분석에 포함하지 않습니다. 실제 Gemini 응답·프로젝트 무료 할당량은 키 등록 후 실행 이력과 AI 패널로 검증합니다.
